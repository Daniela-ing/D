# AVPF-2 – Concreto permeable

Repositorio de trabajo académico sobre concreto permeable.

## Archivos incluidos

- `AVPF1_Concreto_Permeable.ipynb`: notebook de análisis en formato Jupyter/Google Colab.
- `Herramientas_AVP1.xlsx`: archivo de Excel con herramientas/datos del trabajo.
- `AVP1_Herramientas.pdf`: material de referencia en PDF.
- `Informe_Tecnico_Concreto_Permeable.docx`: informe técnico en Word.

## Cómo abrir el notebook

1. Descarga `AVPF1_Concreto_Permeable.ipynb`.
2. Ábrelo en [Google Colab](https://colab.research.google.com/) o Jupyter Notebook.
3. Si el notebook necesita archivos de datos externos, súbelos al entorno antes de ejecutar las celdas.
